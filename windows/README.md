# Windows 10 版開發狀態

這裡是繁體中文 Windows 10 以上版本的開發程式碼，**尚未達到原版 73 項操作的功能對等，也未通過 Windows 10 實機驗證**。請勿將編譯出的程式當成正式版本發行。

目前使用原生 Win32/C++，已建立繁體中文輪盤、檔案選取、OLE 拖放與 Shift 叫出輪盤的程式架構。拖住檔案按 Shift 的跨程式互動仍需實機驗收。部分圖片轉換使用 Windows Imaging Component；音訊與影片操作依賴外部 `ffmpeg.exe`，PDF 操作依賴 Poppler 工具。這些外部工具目前**沒有隨程式封裝**。圖片「去隱私」目前會重新編碼，JPEG 畫質可能受影響，尚未達到原版的無損中繼資料清除方式。

尚缺的原版功能包括圖片去背、OCR、部分 PDF 與文件轉換、文件隱私清理，以及相應的完整測試。Windows 介面的操作清單目前只是對等移植的待辦表，顯示某個格子不表示它已可用。

在 Windows 10/11 開發環境以 Visual Studio 2022 與 CMake 建置：

```powershell
cmake -S windows -B windows/build -G "Visual Studio 17 2022" -A x64
cmake --build windows/build --config Release
```

目標平台是 Windows 10 以上；Windows 8/8.1 已不在支援範圍。正式發行前仍需逐項核對 73 項操作、批次處理、隱私掃描與清除，以及拖曳加 Shift 的輪盤流程。

## 測試版驗收重點

1. 在 Windows 10 電腦解壓縮後啟動 `FormatWheel.exe`，確認標題、輪盤與提示為繁體中文。
2. 直接把 PNG 圖片拖到視窗，確認已加入檔案；點選 JPG 格子，確認新檔出現在原檔旁，原檔未修改。
3. 從檔案總管拖住圖片時按 Shift，確認輪盤出現在游標附近；再按 Shift，確認工具頁切換；鬆開檔案時確認所選格子執行。此互動目前尚未經實機驗證。
4. 對含 EXIF/GPS 的圖片點「去隱私」，用其他工具檢查輸出檔的中繼資料是否已清除。其他檔案種類的隱私功能尚未完成。

回報時請附 Windows 版本、檔案格式、操作步驟、結果與錯誤畫面。請避免提供私人原始檔；可用自行建立的測試檔。
