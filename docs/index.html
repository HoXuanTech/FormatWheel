How it works

三步，比開啟轉換網站還快

  1. 01拖住檔案

    在 Finder 或桌面上拖住一個或多個檔案，先別鬆手。

  2. 02按一下 ⇧ Shift

    螢幕暗下來，輪盤在滑鼠處彈出；再按一次翻到「工具」頁。

  3. 03朝格子一甩，鬆手

    方向對就行，不用拖到格子上。結果存在原檔案旁邊，原檔案不動。

Loadout

輪盤裡有什麼

拖什麼檔案，就彈出什麼輪盤。第 1 頁是格式轉換，按 Shift 翻到第 2 頁是工具。右上角屬性條告訴你這一下會得到什麼、犧牲什麼。

Mission

翻車也要有儀式感

成功時先響一聲武器上膛（手槍拉套筒、霰彈槍“咔嚓”、手雷拔環……），再彈出 MISSION PASSED；失敗就壓暗螢幕打出 WASTED，順便告訴你怎麼修。

Two styles

格子圖示，兩種都有

預設是格式圖示：一眼看出格式本身的特點，PNG 帶透明格、JPG 是風景照、WebP 是瀏覽器、TIFF 是印表機。選單欄 →「格子圖示」可以換成武器：PNG 突擊步槍、JPG 手槍、PDF 火箭筒、摳圖 匕首。

Install

安裝

  1. 下載 FormatWheel.dmg，雙擊開啟，把「FormatWheel」拖進「Applications」。
  2. 如果 macOS 顯示「無法驗證開發者」，先確認下載來源並核對檔案雜湊值。此版本未經 Apple 公證；是否信任與開啟，由使用者自行決定：
    macOS 14

    在「應用程式」裡右鍵點 FormatWheel →「開啟」→ 彈窗裡再點「開啟」。

    macOS 15 及以後

    先雙擊一次，然後去「系統設定 → 隱私與安全性」，拉到下面點「仍要開啟」，輸入開機密碼。

  3. 選單欄會多一個小輪盤圖示（Dock 裡沒有），第一次會自動示範一遍。之後在 Finder 裡拖住檔案、按 Shift 就行。
可選：裝上更多「彈藥」

WebP 需要 cwebp；AVIF、WebM、MP3、Opus、影片變速等需要 ffmpeg。沒裝時這些格子顯示「未裝備」，其他格子照常能用。裝了 Homebrew 的話：

brew install ffmpeg webp
